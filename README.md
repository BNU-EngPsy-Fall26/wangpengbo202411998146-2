## 1. 项目介绍

本项目为《工程心理学》作业二，从 W6（搜索与并行加工）与 W7（显示设计）中各选一个经典范式，
做成同一个可交互网站，并为**每个实验各加入一处有理论依据的改进条件**，
在被试内设计中同时检验经典效应是否复现、改进条件是否生效。

两个实验均为**被试内设计**，都包含完整流程：
实验介绍 → 知情同意 → 匿名编号 → 指导语 → 练习 → 正式实验 → 结果展示。

本项目**不包含**任何服务器、数据库或后台管理系统。试次级数据实时写入浏览器本地存储
（`localStorage`），实验结束后可一键导出 CSV；如需把数据汇总到课程收数接口，
在 `js/config.js` 中填入项目码即可（见第 10 节）。

## 3. 自变量、因变量与条件

### 实验一：Flanker 侧翼干扰（3 × 2 被试内）

**因素一：侧翼刺激类型**

| 水平 | 含义 | 示例（目标为 H） |
|------|------|------------------|
| 完全相同 congruent | 侧翼与目标字母相同 | `HHHHHHH` |
| 反应相容 compatible | 侧翼字母不同、但对应同一按键 | `KKKHKKK`（H、K 均按 F） |
| 反应不相容 incompatible | 侧翼字母对应另一按键 | `SSSHSSS`（S 按 J） |

**因素二：颜色分组方式**

- **经典条件 same**：全部 7 个字母使用同一颜色。
- **改进条件 diff**：中央目标与两侧侧翼使用不同颜色（目标浅色 `#f1f5f9`，侧翼蓝色 `#60a5fa`）。

共 **6 个条件**。按键映射：**H、K → F 键；S、C → J 键**。

**因变量**：正确反应时（ms）、正确率、Flanker 干扰效应（`RT不相容 − RT相容`）。

### 实验二：Cleveland–McGill 图形知觉（单因素三水平被试内）

| 条件 | 说明 |
|------|------|
| A 共同尺度柱状图 | 五个柱共用同一纵轴尺度 |
| B 普通饼图 | 五个扇区，无任何参考刻度 |
| C 带刻度饼图（**新增**） | 在普通饼图外圈增加 `.25 / .5 / .75` 角度参考刻度与由圆心辐射的参考虚线 |

被试任务：判断「较小数值大约是最大数值的百分之多少」，输入 0–100 的数字。
图中**不显示任何数值标签**，只标记「最大」与「较小」对应的元素。

**因变量**：
- 主要：绝对误差 `|估计% − 真实%|`；对数绝对误差 `log₂(|误差| + 1/8)`
- 次要：判断反应时（ms）

## 4. 复现与原论文的区别

1. **实验环境**：原论文在严格控制的实验室环境中完成；本实验在网页浏览器中运行，
   使用 `performance.now()` 高精度计时。网页计时精度受浏览器调度、显示器刷新率、
   设备性能等影响，**不能声称与原论文程序完全一致**。
2. **时间参数**：注视点 500 ms、刺激最长呈现 1000 ms、总反应窗口 1500 ms、
   试次间隔 400–600 ms，均为**网页版建议参数**，需经预测试确认，并非原论文的精确数值。
3. **刺激材料**：Flanker 采用 7 字母横向排列，目标字母为 H、K、S、C 四种；
   原论文使用字母串与噪声字母的变体设计，具体刺激集与试次数不同。
4. **新增条件**：两个实验各增加一个**真实实现、可数据检验**的改进条件，
   这部分在原论文中不存在，属于本研究提出的假设。
5. **呈现方式**：采用深色刺激背景 + 固定注视点，以减少界面元素对注意的干扰。

## 5. 改进方案及理论依据

### 实验一改进：颜色分离目标与侧翼

- **方案**：改进条件下，中央目标字母与两侧侧翼字母使用不同颜色
  （目标 `#f1f5f9`、侧翼 `#60a5fa`）。两种颜色在深色背景上的**亮度与对比度已控制**，
  避免某一种颜色本身更醒目而引入混淆。
- **理论依据**：基于选择性注意的**知觉分组**观点——颜色是强力的知觉分组线索，
  可帮助被试在知觉层面把目标从干扰中分离出来，从而削弱侧翼冲突带来的反应竞争。
  若成立，异色条件下的 Flanker 效应应小于同色条件。

### 实验二改进：饼图增加 .25 / .5 / .75 角度参考刻度

- **方案**：在普通饼图基础上，于外圈增加 `.25 / .5 / .75`（即 90°/180°/270°）角度参考刻度，
  并绘制由圆心向外的参考虚线。**不显示任何可直接推算答案的百分比数字**。
- **理论依据**：Cleveland & McGill 指出不同图形编码的精度不同——位置编码（柱状图的长度）
  通常优于角度/面积编码（饼图）。**Hollands & Dyre (2000)** 进一步表明，
  为饼图提供刻度参考可减少比例判断的偏差。因此预测改进条件能降低判断误差。

## 6. 事前研究假设

> 以下假设在正式收集数据**之前**写入本文件并完成 Git commit。

- **H1**：反应不相容条件下的反应时大于反应相容条件（经典的 Flanker 干扰效应）。
- **H2**：目标与侧翼采用不同颜色时，反应不相容产生的额外反应时成本
  （Flanker 效应）**小于**全部同色条件。
- **H3**：共同尺度柱状图的比例估计误差**低于**普通饼图（经典图形编码效应）。
- **H4**：具有角度参考刻度的饼图，其比例估计误差**低于**普通饼图（改进效应）。

**核心计算**

- Flanker 效应 `= RT(不相容) − RT(相容)`，分别在同色 / 异色条件下计算，再比较二者之差。
- 绝对误差 `= |估计% − 真实%|`；对数绝对误差 `= log₂(绝对误差 + 1/8)`，百分比用 0–100 刻度。

## 7. 每个条件的正式试次数

会话长度由 `js/config.js` 的 `APP_CONFIG.session.mode` 统一设定，被试无法选择；
实际取值写入每条数据记录（`session.mode` / `session.perCondition`）与 CSV 的 `sessionMode` 列。

| 会话长度 | 配置值 | Flanker（6 条件） | Cleveland–McGill（3 条件） | 练习试次 |
|----------|--------|------------------|---------------------------|---------|
| **标准**（默认） | `standard` | 每条件 16 → **96** | 每条件 16 → **48** | 12 / 6 |
| 精简 | `short` | 每条件 12 → **72** | 每条件 12 → **36** | 12 / 6 |

- **标准版用于正式收集数据**（本 README 报出的结果均基于标准版）。
- 精简版用于预测试、演示或被试时间紧张时；两档**任务难度完全相同**，
  只改变每条件的测量次数，因此两档数据不可混合统计，需分别报告。
- 临时切换（不改文件）：在网址后加 `?session=short` 即按精简版运行，
  例如 `flanker.html?session=short`。该参数只影响当前这一次访问，
  正常被试不带参数，仍按 `config.js` 的设定执行。
- Flanker 每条件试次数必须是 **4 的倍数**（4 个目标字母要完全平衡）：
  16 → 每目标每条件 4 次、每目标字母 24 次；12 → 每目标每条件 3 次、每目标字母 18 次。
  若配置成非 4 的倍数，程序自动退回 16，保证平衡不被破坏。
- 图形知觉：三个条件使用同源的比例分布池（较小值占最大值的 20%–80%），
  比例分布与题目难度在条件间可比较，试次顺序随机化。

两档均满足「每个条件至少 10 个正式试次」的验收下限（Flanker 12、图形知觉 12）。

## 8. 实验操作说明

**通用流程**：打开首页 → 选择实验 → 阅读介绍 → 勾选知情同意 → 生成/输入匿名编号 →
阅读指导语 → 练习（有反馈）→ 正式实验（无反馈）→ 结果展示。

**实验一（Flanker）**
- 注视点 `+` 出现 500 ms 后，呈现 7 个字母。
- 只判断**正中间**的字母：`H`/`K` 按 **F**，`S`/`C` 按 **J**。
- 刺激最长呈现 1000 ms，总反应窗口 1500 ms，超时记为错误。
- 页面失焦时当前试次标记为无效（`invalid=1`）。

**实验二（图形知觉）**
- 每试次显示一个含五个数值的图表，红色标「最大」、蓝色标「较小」。
- 判断「较小约是最大的百分之多少」，输入 0–100，按 Enter 或点击提交。
- 练习阶段给出正确答案，正式阶段不提供任何反馈。

**Flanker 单试次字段**

| 字段 | 说明 |
|------|------|
| `cond` | 条件标签，如 `incompatible-diff` |

| 字段 | 说明 |
|------|------|

| `maxIdx` / `smallIdx` | 最大与较小元素在数组中的位置（用于还原图形） |

**本地保存（始终执行）**

**与接口约定的对应关系**

| 接口要求 | 本项目的处理 |
|----------|-------------|
| `project` 六位项目码 | `config.js` 的 `DEFAULT_PROJECT` |
| `experiment` 仅小写字母/数字/`_`/`-` | `flanker_improved`、`cleveland_improved` |
| `condition` 为被试间分组（可选） | 留空：本设计全部为被试内条件 |
| 每试次值只能是数字/字符串(≤2000字)/布尔/数字数组(≤500项) | 全部为标量，无嵌套对象 |
| 每试次 ≤ 40 字段、单次 ≤ 256 KB | 10 个字段、约 15 KB |
| 返回 `{ok:true, record_id, participants, warnings?}` | 结果页显示记录号与累计被试数 |
| 返回 `ok:false`（如项目码写错） | 视为失败，显示后台给出的 `msg`，不误报成功 |
| `warnings`（字段被转换或截断） | 结果页以警示色显示，提示需改代码 |

**实现要点**

- 提交成功后写入本地标记，**再次打开不会重复提交**。
- 提交失败（断网、项目码错误、后台拒收）时数据保留在本地并可导出 CSV，不影响结果页展示。
- 页面不包含**下载密钥**，前端只做写入，不持有读取权限。
- 如需临时关闭上传，把 `DEFAULT_PROJECT` 置空即可，不发出任何网络请求。

## 11. 数据清理方法

**Flanker**
- 反应时统计**仅纳入** `rt !== null` 且 `timedOut = 0`、`invalid = 0` 的试次。
- 超时与失焦试次**计入正确率分母**（记为错误），但**不计入** RT 均值。
- 可选进一步剔除偏离条件均值 ±3 SD 的试次；网页默认保留原始数据，便于复核。

**Cleveland–McGill**
- 估计值限定在 0–100，超出范围的输入会被拒绝并提示重新输入。
- 绝对误差与对数绝对误差按前述公式计算，试次级数据完整保存。
- 建议在合并多名被试数据前检查是否存在明显异常快（< 0.3 s）的试次。

**多名被试的合并分析**
- 把每名被试导出的 CSV 合并后，**先按被试计算条件均值**，再对**被试级均值**求跨被试平均，
  避免试次多的被试权重过大。
- 效应量 = 逐被试效应值的平均；95% CI 用 t 临界值 × 标准误。
- 被试数 < 5 时不做推断统计，只报告描述统计量。

## 13. 经典效应与改进条件的比较

**比较逻辑**

| 假设 | 比较对象 | 支持条件 |
|------|----------|----------|
| H1 | 不相容 RT vs 相容 RT | 差值为正 |
| H2 | 同色效应 vs 异色效应 | 同色效应更大（差值 > 0） |
| H3 | 饼图误差 vs 柱状图误差 | 饼图误差更大（饼 − 柱 > 0） |
| H4 | 普通饼图误差 vs 带刻度饼图误差 | 带刻度更低（饼 − 刻度 > 0） |

**统计方法**：均为被试内设计，采用**被试级配对比较**——先算每名被试的效应值，
再对效应值做单样本 t 检验（检验是否偏离 0），并报告均值、标准误与 95% 置信区间。
结果页的森林图直接呈现「预测方向 vs 实测效应 + CI」。

**与原论文的对照方式**：只做**效应方向的对照**，不做数值的逐点等同。
原论文的误差绝对值来自其特定刺激材料与实验室条件，与网页实验不可直接比较。

## 14. 研究局限

1. **样本量小**：每条件试次有限，且计划招募的被试数量较少，统计效力低，
   结果不应过度外推。显著性检验基于小样本，p 值需谨慎解读。
2. **网页计时精度**：`performance.now()` 提供高精度时间戳，但浏览器调度、
   显示器刷新率（通常 60 Hz，约 16.7 ms 一帧）、系统负载仍会引入误差，
   反应时精度不及专业实验设备。
3. **环境不可控**：被试在不同设备、光照、屏幕尺寸与观看距离下完成实验，
   刺激的视角大小无法统一控制。
4. **被试内设计固有风险**：可能存在练习效应、疲劳效应与顺序效应；
   已通过试次随机化缓解，但未做拉丁方平衡。
5. **改进条件的生态效度**：颜色分离与角度刻度是特定实现方式，
   其效果是否可推广到其他刺激材料或真实界面设计，需要进一步研究。
6. **眼动指标粗略**：WebGazer 基于摄像头估计，未做校准，仅能提供非常粗略的注视区域信息。
7. **图形知觉的 `correct` 字段**：收数接口要求 `correct`，本实验以「绝对误差 ≤ 10 个百分点」
   作为约定映射，该字段本身不是本实验的主要因变量（主要因变量是连续的误差值）。

## 16. 如何在本地运行

### 方式一：直接打开（最简单）

1. clone 或下载本仓库到本地。
2. 双击 `index.html`，或右键选择用 Chrome / Edge 打开。
3. 点击实验入口即可开始。

> 此方式下实验与数据记录、CSV 导出全部正常。
> 仅**眼动模块**不可用（浏览器禁止 `file://` 页面访问摄像头），页面会自动禁用该开关并说明原因。

### 方式二：本地服务器（推荐，可启用眼动模块）

在项目根目录执行：

```bash
# Python 3
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

- 两种方式下实验流程、数据记录与 CSV 导出完全一致，无需任何构建步骤或依赖安装。
- 如需把数据提交到收数接口，需联网，并在 `js/config.js` 中填写项目码。
